# Casos de referencia

Activo **A2** del loop maestro. Un fichero por campaña publicable, con la plantilla
`plantillas/caso-referencia.md`:

```
docs/casos/{{año}}-{{municipio}}-{{linea}}.md
```

**Requisitos para que un caso viva aquí:**

1. Autorización expresa de la institución, por escrito.
2. Evidencia de nivel 3 como mínimo (el caso necesita números).
3. Consentimiento de imagen archivado para toda fotografía incluida.
4. Versión en euskera revisada.

Objetivo: **≥ 4 casos publicables por año** (`loop/tablero-loop.md`).
