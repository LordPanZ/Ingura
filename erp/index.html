¿Cómo funciona?

  1. La primera sesión que abre el sistema cada día (control en Firestore) ejecuta el backup automáticamente.
  2. Se descarga un archivo backup_ingura_AAAA-MM-DD.json con todas las colecciones.
  3. Se envía el JSON por email vía EmailJS al correo configurado.
  4. Configura tus credenciales de EmailJS al final del archivo (EMAILJS_CONFIG).
