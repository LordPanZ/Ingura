## 8. Diagnóstico de fallo

Cuando el negocio no va bien, el tablero dice **dónde** se ha roto el loop:

| Síntoma | Estación que falla | Qué revisar |
|---|---|---|
| No entran oportunidades | ① Escucha | ¿Está el radar activo? ¿Está la cartera actualizada? ¿Se ha prospectado en el mes equivocado? |
| Entran oportunidades pero no se convierten | ② Propuesta | ¿Falta la capa justificativa? ¿Se propone al cliente equivocado? ¿El precio está mal explicado? |
| Se gana pero el cliente no queda satisfecho | ③ Ejecución | ¿Falta kit cerrado? ¿Exceso de improvisación? ¿Capacidad sobrepasada? |
| Cliente satisfecho pero no repite | ④⑤ Evidencia y Devolución | **La causa más frecuente.** No se le dio nada con lo que justificarse ni motivo para volver. |
| Repite pero no llegan clientes nuevos | ⑥ Prescripción | No se publican casos ni se pide recomendación. El loop gira pero no se amplía. |
| Crece la facturación y no los activos | Todo el loop | Se está vendiendo, no construyendo. Revisar §2 de este tablero. |
