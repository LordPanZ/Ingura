# Plan de relanzamiento comercial — INGURA

**Educación ambiental · Euskadi · Desde 2022**

Este repositorio contiene el sistema comercial completo para relanzar Ingura: el
diagnóstico, el catálogo reempaquetado, el **Loop Maestro Comercial**, el
calendario de las 4 ventanas del año, los objetivos con su embudo, el mapa de
cuentas, el plan de 90 días y todas las plantillas listas para usar.

> Fecha de partida del plan: **18 de agosto de 2026**.
> La primera ventana comercial del año (subvenciones a entidades locales) se abre
> a finales de septiembre. Quedan **5 semanas**. Todo el plan está ordenado
> alrededor de esa cuenta atrás.

## La idea en una frase

> Ingura vende economía circular. El problema es que su cartera de clientes es
> lineal: se capta un ayuntamiento, se ejecuta el proyecto y se tira. **El Loop
> Maestro convierte cada proyecto terminado en la materia prima del siguiente:
> memoria → renovación → prescripción → nueva cuenta.** Cero residuo comercial.
